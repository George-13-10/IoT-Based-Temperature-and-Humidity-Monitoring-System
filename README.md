# IoT Temperature and Humidity Monitoring System

This project is an IoT-based system that monitors temperature and humidity using an ESP8266 NodeMCU and DHT11/DHT22 sensor.

The data is sent to the ThingSpeak cloud platform, where it can be viewed in real time through a dashboard.

## Features
- Real-time temperature and humidity monitoring  
- Cloud data storage using ThingSpeak  
- Remote access from anywhere  
- Low-cost implementation  

## Components Used
- ESP8266 NodeMCU  
- DHT11 / DHT22 Sensor  
- Arduino IDE  
- ThingSpeak  

## Working
The sensor reads temperature and humidity data, which is processed by the ESP8266 and sent to the cloud every 10 seconds. The data is then displayed on a dashboard.

## Applications
- Smart homes  
- Greenhouses  
- Laboratories
